CoSTAR Events — Staff Admin

Adds, edits and removes events directly in the live calendar's events.json file on GitHub.

⚠️ This page hasn't been configured yet. Open admin.html in a text editor and fill in REPO_OWNER and REPO_NAME near the top of the script before giving this page to staff.

Connect

You'll need a GitHub personal access token with permission to edit this one repository. If you don't have one yet:

  1. On GitHub, go to Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Under "Repository access", choose Only select repositories and pick this calendar's repo.
  3. Under "Permissions", set Contents to Read and write. Leave everything else as-is.
  4. Set an expiry (e.g. 90 days) and click Generate token. Copy it — you'll only see it once.

This is kept only in this browser tab's memory for this session — it is never saved into any file, and clears when you close the tab or click "Sign out".
